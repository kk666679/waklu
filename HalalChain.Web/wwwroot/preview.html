Data Flow
data-flow.txt
PlatformApiClient  ← seed data / HTTP to Platform API
  │  GetProductsAsync(), GetOrdersAsync(), GetCustomersAsync()
  │  CreateOrderAsync(), SemanticSearchAsync()
  ↓
AppState  ← reactive state + filters
  │  Products[], Orders[], Customers[], Categories[], Vendors[]
  │  SearchQuery, SelectedCategory, SelectedHalalStatus
  │  FilteredProducts (computed)
  │  OnChange event → pages subscribe
  ↓
Pages  ← @inject AppState / CartState / NotificationState
  │  Products.razor  → search + category + halal filter
  │  Cart.razor      → quantity controls + free shipping
  │  Checkout.razor  → validated form + order submission
  │  Admin/*.razor   → DataTable with sort/search/export
  ↓
Components  ← shared Blazor components
  ProductCard, DataTable, Button, Modal, Alert, Chatbot,
  SmartSearch, CtaBanner, Avatar, Skeleton, Toast...

Architecture
system-architecture.txt
Browser
  ↓
HalalChain (Blazor) / Marketplace (MVC)  ← JWT auth
  ↓
Platform API (.NET 10) — Modular Monolith
  ├── Modules/Identity, Catalog, Halal, Commerce, AI
  ├── PostgreSQL ← Catalog, Vendors, Orders, Halal records
  ├── Redis ← Cart session, cache
  ├── ai-inference ← Embeddings, classify, rerank
  └── tawheed ← Multi-agent evidence + Policy Engine
.NET Projects
  • Platform.Contracts — shared DTOs
  • Platform.Api — core REST API
  • HalalChain — Blazor frontend
  • Marketplace — MVC frontend
  • Platform.Tests — xUnit tests
